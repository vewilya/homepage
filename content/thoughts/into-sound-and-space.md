This is the first note on a site that is still taking shape. It replaces a
one-page placeholder that played a loop and said "check back soon".

What will show up here: notes on sound and space, on the tools I build to
work with both, and on the odd detour in between. Short when it can be,
longer when it has to be.

The site itself is plain markdown rendered by Nuxt Content. Each post is one
file in a folder. No database, no editor, no comments. If something here is
worth a reply, the links in the footer are where to find me.
